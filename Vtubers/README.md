# RuVtubers analyzation

Some statistics about ruvtubers community on twitch

## Vtubers criteria

* Face tracking model (Live2D, VRoid, etc)
* Streaming on Twitch
* 1000+ followers on Twitch

## Vtubers list

Stored in the [vtubers.txt](./data/vtubers.txt) file.

Lines, started with `#` are ignored. 
Every other line is interpred as vtuber name in the sample. 
For every line there must be an account with link `https://www.twitch.tv/{line}`
